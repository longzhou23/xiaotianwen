# 图片上下文缓存池

这是一个独立的 AstrBot 插件，负责把图片消息保存为稳定的本地副本，并在同一会话后续出现“这个、那张、解析一下、看看这张”等指代性文字时，将最近图片重新挂载到本次 LLM 请求。

它不负责图片描述、场景推断或主动聊天；这些功能继续由其他插件提供。默认每个会话保留 3 张图片，缓存回放有效期为 30 分钟。

## 与 ContextAware 的分工

- 本插件：图片缓存、会话图片池、ProviderRequest 图片回放。
- ContextAware：群聊场景、发言关系、图片描述和场景提示。

## 典型用法

```text
用户：发送一张星空图
用户：解析一下
```

第二条消息不需要重新发送图片，插件会回放第一条消息的稳定图片副本。

## 图片 ID 和描述回放

每张缓存图片都会得到一个类似 `img-19a2f3c8-4d21ab` 的 ID。ContextAware 首次生成图片描述后，本插件会从场景提示中记录该描述，并向后续请求注入：

```xml
<image_cache_index>
  <image id="img-...">首次视觉描述：...</image>
</image_cache_index>
```

默认情况下，后续“这个/解析一下/看看那张”等请求只使用 ID 和首次描述，不重复发送图片；只有“重新看原图、看清细节、放大、识别”等请求才会回放原图。
