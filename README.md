# 小天文（Public）

这是小天文的公共代码仓库工作区，目标是保存可公开维护的插件源码、通用组件、部署脚本和文档。

本仓库不包含：

- `.env`、API Key、Token、证书和私钥；
- QQ 登录数据、用户画像、聊天记录和好感度数据；
- Iris/知识库数据库和向量索引；
- `.runtime`、Python 虚拟环境、浏览器运行时和模型缓存；
- 运行日志、临时媒体和实例数据库。

## 目录

```text
plugins/
  upstream/       未确认本地差异的第三方插件
  modified/       二次开发或本地自研插件
  retired/        已停用但保留来源的插件
  manifest/       来源、许可证和修改状态
components/       可公开维护的通用组件
deploy/            不含凭证的部署模板
scripts/           启停、诊断和安装脚本
config/            配置模板，不含实例值
docs/              设计、迁移和运维文档
```

## 部署原则

公共仓库只负责安装代码和生成运行环境。实例数据从对应的 private 仓库或独立备份恢复，真实密钥通过部署机器上的 secret 文件或环境变量注入。

当前插件来源和本地修改状态以 `plugins/**/plugin.meta.yaml` 为准；其中标记为 `upstream-diff-required` 的插件在首次公开发布前必须与上游做差异审查。
